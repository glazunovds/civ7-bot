# Expansion Planner: in-game test checklist

The mod is linked into the game with a folder junction:
`%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods\expansion-planner` points to `mod\expansion-planner`.

`AppOptions.txt` has UI hot reload, UI logging and debug panels turned on. The backup is `AppOptions.backup-2026-10-11-xpl.txt` in the same folder.

## Before you start
1. Start the game, open **Add-Ons**, and enable **Expansion Planner** (Планировщик экспансии).
2. Load a save or start a game. A save with a few settlements is best.
3. After testing, tell Claude. It reads `Logs\UI.log` and `Logs\Modding.log` itself.
   - All mod lines start with `[XPL]`.
   - To watch them live, run `powershell -File tools\tail-ui-log.ps1`.

## Things the logs tell us (no action needed)
- `[XPL] map WxH wrapX=… hex geometry verified`: our hex maths matches the game's.
- `[XPL] rules loaded for AGE_…: N common buildings …`, which also shows `CITY_MIN_RANGE`.
- `[XPL] game loaded; dmt=L1 dmtPatch=true|false`.
- `[XPL] sites: … scanned … in N ms`: performance.
- `[XPL] placed N tack(s) …`, plus a warning if a write did not land.
- `[XPL] queued|bought BUILDING_… at tack x,y`: a production-menu tack button was used.
- `[XPL] wonder planner: N wonders (M available), K cities, fair|omniscient, N ms`.
- `[XPL] buildings: … for c:x-y+…: area …, horizon …, N uniques`: the region and timing plan.
